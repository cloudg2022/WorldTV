# World TV
PWA estática para explorar y reproducir streams públicos del catálogo IPTV-org, con prioridad visual para España/español, favoritos, filtros, Picture-in-Picture y carga local de listas M3U.

## GitHub Pages
Sube el contenido de esta carpeta a la raíz de un repositorio. En Settings > Pages selecciona Deploy from a branch, `main`, `/(root)`.

## Limitaciones
Algunos streams pueden fallar por geobloqueo, CORS, DRM, caducidad o incompatibilidad del navegador. La aplicación excluye canales marcados NSFW y streams que declaran requisitos de Referer/User-Agent.
